# CCNA Modules 16–17 — Building and Securing a Small Network

Independent interactive practice reviewer aligned with the CCNA 1 v7 Modules 16–17 subject areas.

## Features

- 67 original, reworded quiz questions; single- and multiple-answer items
- Practice and Flashcards modes
- Retry missed questions, Shuffle, Question Jump
- Correct-count and streak tracking
- Reset button clearing locally saved progress and returning to Question 1
- Responsive, standalone HTML (no additional dependencies)

## Publish with GitHub Pages

1. In repository Settings → Pages, choose `Deploy from a branch`, branch `main`, folder `/(root)`, and Save.
2. Once published, the site should be at `https://1erdna.github.io/CCNA-16-17-Quiz/`.

[ITExamAnswers CCNA v7 Modules 16–17](https://itexamanswers.net/ccna-1-v7-modules-16-17-building-and-securing-a-small-network-exam-answers.html)
